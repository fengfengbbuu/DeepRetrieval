# 任务

## 任务1：
任务描述：用代码实现我自定义 metric，评估模型结构化的输出结果。

自定义 metric:
- 简介：评估模型输出的结构化文本，并为其打分。
- 预期的模型输出格式：预期的输出格式见 `task_log/analyze/expect_output_format.txt` 文件。读取该文件你会发现输出格式中有一个 `<think></think>` tag 和一个 `<answer></answer>` tag，且 think 在前，answer 在后。
- 评估逻辑：
    - 如果存在 `<think>{content}</think>` 做一个 flag 标记。如果 think tag 仅有一个，再做一个标记。
    - 如果存在 `<answer>{content}</answer>` 做一个 flag 标记。如果 answer tag 仅有一个，再做一个标记。
    - 抽取 `<answer>{content}</answer>` 中的 content 信息，该信息格式应当是 `'{"sql": "..."}'`，一个字典且仅有一个 `'sql'` key。具体参考 `task_log/analyze/expect_output_format.txt`。如何 content 符合格式，做一个 flag 标记。
    - 如果上面的标准全都满足，即完全符合 `task_log/analyze/expect_output_format.txt` 中的格式信息，再做一个 flag 标记，表示模型输出信息的格式完全正确。
- 提示：你可以分层次完成该功能。比如写一个专门用于处理数据格式的函数，再写一个专门评估模型输出的函数。
